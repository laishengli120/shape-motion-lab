# 图形小实验室

面向小学数学课堂的图形运动教学辅助工具。在格点图上探索图形的平移、旋转和轴对称，支持预设题目、自定义绘制和触屏操作。

## 功能

- 选择三角形、正方形、箭头、小旗、房子等预设图形
- 在格点图上点击绘制自定义多边形
- 拖动图形完成平移，结果会保留在后续操作中
- 选择旋转中心后，通过触摸拖动或角度输入完成任意角度旋转
- 选择中间横轴或中间竖轴完成轴对称，另一侧实时显示镜像
- 可自由开关对称图形显示，支持在轴的左/右或上/下任意一侧绘制
- 使用内置题目预设快速开始练习
- 当前版本不包含拍照或图片上传功能

## 开始使用

```bash
npm install
npm run dev
```

打开终端提示的本地地址，通常是 `http://127.0.0.1:5173/`。

## 校验

```bash
npm test
npm run build
```
